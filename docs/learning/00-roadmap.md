# memento-mori Learning Roadmap

The idea: build **one evolving app**, a life-in-weeks tracker. The Go
backend comes first, so the language is learned on pure, testable logic
before any HTTP or storage. Then a React frontend goes deep on the TanStack
ecosystem. Each project ends with a clear outcome, and each is split into
small steps when it starts.

---

## Project 0: Setup

- Install Go (Homebrew)
- Repo, monorepo layout (`api/`, `web/`, `docs/`), GitHub remote
- Working rules (`CLAUDE.md`), commenting standards, roadmap/progress/journal

**Outcome:** an empty but well-organised repo, ready for the first line of Go.

---

## Project 1: Go Foundations & the Pure Domain

The week maths, with no HTTP and no storage.

- `go mod init`, the standard layout (`cmd/server`, `internal/life`), what `internal/` enforces
- Go basics in context: packages, structs, methods, `const` + typed strings (enum-style), errors as values
- `time.Time`, and normalising dates to UTC midnight (DST off-by-one traps)
- `BuildSummary`: weeks lived, current week, weeks remaining (clamped for future birthdates and for ages past the target)
- Per-week cells with date ranges and a decided **week-53 rule** (rows = age-years starting at each birthday, leftover days fold into week 52, so the grid and the counter agree)
- Table-driven tests with `testing`: leap-day birthdays, exact birthdays, future dates, past target age
- `go vet`, `gofmt`, `golangci-lint`, test coverage

**Outcome:** a fully tested `life` package you'd trust with anyone's birthday.

---

## Project 2: JSON API

- `net/http` with Go 1.22 routing (`GET /api/summary`, path/query params)
- Input validation and a consistent JSON error shape (400 vs 200)
- Handler tests with `net/http/httptest`
- Middleware: `log/slog` request logging, panic recovery, CORS for the Vite dev server
- Config from env vars, and graceful shutdown with `context` + `os/signal`

**Outcome:** a small, tested, production-shaped Go HTTP API with no framework.

---

## Project 3: Frontend Foundation

- Vite + React + TypeScript (strict), ESLint, Prettier
- Tailwind v4 + **shadcn/ui**
- **TanStack Router**: file-based routes, type-safe search params (`?birthDate=&targetYears=`)
- **TanStack Query**: fetching the summary, caching, loading/error states
- **Zod**: validating API responses at the boundary (backend DTO → UI types)
- **Zustand** (with `persist`): user settings (birthdate, target years, theme)
- A first static 100 × 52 grid with lived / current / remaining states

**Outcome:** the Go API visualised in a typed, well-structured React app.

---

## Project 4: Interactive Grid

- Hover/click inspector (shadcn Tooltip/Popover): date range and age for a week
- **TanStack Form** + Zod for the settings form
- Life-stage bands (childhood, education, career, …)
- Performance with 5,200 cells: event delegation, memoisation, profiling; **TanStack Virtual** where it helps (mobile)
- Dark mode, accessibility (keyboard navigation through the grid)
- **Vitest** + Testing Library, with **MSW** mocking the API

**Outcome:** a polished, tested, interactive grid.

---

## Project 5: Persistence & Notes

- SQLite via `modernc.org/sqlite` (pure Go, no cgo), `database/sql`
- Migrations with `goose`
- A repository interface (and why Go interfaces are defined by the consumer)
- Notes/milestones CRUD per week, with tests against a real temp database
- Frontend: TanStack Query mutations with optimistic updates, and **TanStack Table** for a notes/milestones list

**Outcome:** reflections that persist, end to end.

---

## Project 6: Ship It

- Go `embed`: one binary serves the API and the built SPA
- Multi-stage Dockerfile
- OpenAPI spec, with TS types generated by `openapi-typescript`
- GitHub Actions CI: Go test/vet/lint plus web lint/typecheck/test/build
- Deploy

**Outcome:** a deployed, CI-checked app you can link to in a portfolio.

---

## Project 7: Stretch (v2)

- Accounts and auth
- PostgreSQL instead of SQLite
- Export / shareable snapshots of the grid
- **Playwright** E2E tests

**Outcome:** multi-user memento-mori.
