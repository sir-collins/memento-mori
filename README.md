# memento-mori

A life-in-weeks tracker. Enter a birthdate and a target lifespan, and see
your whole life as a grid of weeks (100 years × 52 weeks = 5,200 boxes):
the weeks lived, the current week, and the weeks left.

Built as a learning project:

- **Backend:** Go (standard library `net/http`, no framework) in [`api/`](./api)
- **Frontend:** React + TypeScript (TanStack Router/Query/Form/Table,
  Zustand, shadcn/ui, Zod) in [`web/`](./web)
